What's real here

Real: the routing decision, the factor analysis, the redaction pass (it runs in this page, before anything is sent), the placeholder substitution on the way back, the settings, the privacy ledger, and the model answers themselves — every path calls a live Claude model on your own account, with a different tier per route.

Not real: the NPU, CPU and memory readings, which a browser cannot see. The on-device path also runs through the network here, using the fastest tier under a tight prompt to stand in for a compressed local model. On the Android build that one call becomes an ONNX Runtime session and nothing changes above it.
